Install the SDK

One line to get started. Each guide covers configuration, placements and entitlements.

Swift Package Manager
.package(url: "https://github.com/billdogai/billdog-ios-spm.git", from: "1.1.1-beta.5")

Full guide: billdog.io/docs/ios

app/build.gradle.kts
implementation("io.billdog:billdog-compose:1.1.1-beta.5")
implementation("io.billdog:billdog-paywall:1.1.1-beta.5") // Google Play Billing

Full guide: billdog.io/docs/android

Terminal
flutter pub add billdog_flutter:^1.1.1-beta.5

Full guide: billdog.io/docs/flutter

Terminal
npm install @billdog.io/react-native@^1.1.1-beta.5 \
  @react-native-async-storage/async-storage@^1.19.0 \
  react-native-fs@^2.20.0 react-native-svg@^13.0.0 react-native-webview@^13.0.0

Full guide: billdog.io/docs/react-native

Terminal
npm install @billdog.io/web@^1.1.1-beta.5

Full guide: billdog.io/docs/web

Open source on GitHub

SDK distributions, integrations and the MCP server.

billdogai/billdog-mcpMCP server: set up paywalls, subscriptions, A/B tests and analytics from Claude Code, Cursor and other AI coding agents. billdogai/billdog-ios-spmiOS SDK (Swift Package Manager): paywalls, in-app subscriptions, analytics and A/B tests for iOS apps. billdogai/billdog-ios-superwallSuperwall PurchaseController that runs every Superwall paywall purchase and restore through BillDog. billdogai/billdog-android-fullBillDog Full SDK for Android: compiled AAR artifacts (paywalls, subscriptions, analytics). billdogai/billdog-android-engBillDog Eng SDK for Android: compiled AAR artifacts. billdogai/billdogeng-goServer SDK for Go: analytics, feature flags, surveys, messaging and LLM observability. billdogai/billdogeng-phpServer SDK for PHP: analytics, feature flags, surveys, messaging and LLM observability.
